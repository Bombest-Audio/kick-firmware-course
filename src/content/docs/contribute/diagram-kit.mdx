Every diagram in the course is plain HTML and CSS from `src/styles/course.css`. No image tool is involved, so labels stay correct and anyone can edit them in a pull request. Colors come from the layer palette on the Start here page.

## Layer chips and the hardware badge

Use `<span class="layer layer-audio">Audio thread</span>` for a layer chip. The layer classes are `layer-hardware`, `layer-bootloader`, `layer-kernel`, `layer-userspace`, `layer-message`, `layer-audio` and `layer-storage`.

Use `<span class="not-verified">Not verified on hardware</span>` for anything nobody has checked on a real unit.

## Code citations and quizzes

Cite code with `CodeRef`. The citation checker (`scripts/check-citations.mjs`) verifies the path, line and expected text against the pinned upstream commit, so a wrong line fails the check. See any lesson for the pattern, and use `Quiz` for the five-question check at the end.

## Rules

- Never generate a diagram with an image model. Hand-build it from these parts.
- One color per layer, everywhere.
- Every diagram gets a caption that says what to notice.
- Test at 375px wide. The kit stacks vertically on small screens.
